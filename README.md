# Ishaan Desai — Portfolio

Personal portfolio site built with React, showcasing my projects, background,
and contact information.

**Live site:** [ishaandesai.vercel.app](https://ishaandesai.vercel.app)

## Overview

A single-page React app with:

- **About** — background, education, and interests
- **Projects** — SkySense (drone detection), Parallel Monte Carlo Options
  Pricing, Panoramic Scene Reconstruction, and Swarm Robotics
- **Currently Building** — in-progress work (FPL optimization pipeline, NFL
  survivor pool win-probability model)
- **Contact** — email, LinkedIn, GitHub, and resume

## Tech Stack

- React (Create React App)
- CSS (custom, no framework)

## Running Locally

```bash
npm install
npm start
```

Runs at `http://localhost:3000`.

## Building for Production

```bash
npm run build
```

## Testing

```bash
npm test
```

## Deployment

Deployed on Vercel, auto-deploys from the main branch on every push.
